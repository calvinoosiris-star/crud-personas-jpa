#CRUD de Personas - Java + JPA
Este proyecto lo hice como practica de backend como para entender y adaptarme bien a como funciona la persistencia de datos en Java usando JPA(Hibernate) y una base de datosMySQL.
La idea no fue solo poder llegar hacer un CRUD , sino entender que pasa por atras cuando trabajamos con una base de datos desde java.

¿Que hace el proyecto?
Trabaja con una entidad Persona y lo que permite es:
-Crear personas(INSERT)
-Listar Personas(READ)
-Actualizar Personas(UPDATE)
-Eliminar Personas(DELETE)

·Que estuve practicando
-En este proyecto trabaje con conceptos importantes como:
-Uso de EntityManager
-Manejo de transacciones(Begin, commit, Rollback)
-Patron DAO(separar la logica de acceso a datos)
-Organizacion del proyecto en capaz
-Uso de JPA con Hibernate

·Tecnologias
-Java
-JPA(Hibernate
-MySQL
-XAMPP
-Maven
